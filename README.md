## About the application

**Movie Search App** is a web application that allows users to search for movies and explore information about them.

Users can enter a movie title into the search field. The application retrieves matching results from the OMDb REST API and displays them on the page. Users can also select a movie to view additional information.

## Technologies

- **HTML** – Defines the structure of the application, including the search field, buttons, messages and movie results.
- **CSS** – Controls the visual appearance and layout of the application, including the movie cards and search interface.
- **JavaScript** – Adds the application functionality, user interactions, DOM manipulation and event listeners.
- **Fetch API** – Makes asynchronous HTTP requests to retrieve movie information from the OMDb REST API.
- **OMDb REST API** – Provides the movie data displayed in the application.

## How to use the application

1. Open the application in browser.
2. Enter a movie title in the search field.
3. Click the Search button.
4. Browse the matching movie results.
5. Click the More info button to see additional information about a movie.

## Running the application locally

1. Clone or download the project repository.
2. Open the project folder.
3. Configure your own OMDb API key in `script.js`.
4. Open `index.html` in a web browser.
5. Search for movies using the search field.
